# YEKDB 1.0.14 — Sprint 01-01 yama notları

## macOS launcher güncellemesi

- Güncelle butonu mimariye uygun `YEKDB-x.y.z-arm64.dmg` veya
  `YEKDB-x.y.z-x86_64.dmg` paketini GitHub Releases üzerinden indirir.
- GitHub asset SHA-256 özeti zorunludur. İndirme boyutu ve özeti doğrulanır.
- Salt okunur bağlanan DMG içindeki uygulamanın bundle kimliği `com.yekdb.app`,
  sürümü, çalıştırılabilir dosya mimarisi ve codesign bütünlüğü doğrulanır.
- Yeni bundle aynı diskte hazırlanır. Launcher kapandıktan sonra kurulur ve
  yeniden açılır. Değiştirme veya açma komutu başarısız olursa eski bundle geri alınır.
- Eski uygulama `.yekdb-update-*/previous.app` altında, kurulum çıktısı aynı
  klasörde `install.log` olarak saklanır. Veri klasörleri değiştirilmez.
- Açık YEKDB motoru varsa veya uygulama klasörü yazılabilir değilse kurulum
  durdurulur. Yönetici yetkisi kendiliğinden istenmez; DMG içinden çalıştırmak
  yerine uygulamanın yazılabilir bir Applications klasöründe bulunması gerekir.

## Dağıtım ve doğrulama sınırları

1.0.12 launcher otomatik macOS güncellemesi içermez. Kullanıcıların bu özelliği
edinmek için 1.0.14'ü ilk kez elle kurması gerekir; sonraki daha yüksek sürümlerde
launcher üzerinden güncelleme kullanılabilir. Her mimari için uygun DMG ve
SHA-256 digest içeren release asset yayınlanmalıdır.

Mevcut paketleme ad-hoc imza kullanır. Codesign kontrolü bundle bütünlüğünü
kontrol eder; Developer ID yayıncı doğrulaması veya Apple notarization sağlamaz.
Gatekeeper politikaları devre dışı bırakılmaz. Açma komutunun başarısı uygulamanın
sağlıklı başladığını kanıtlamaz; güç kesintisi kurtarması ve başlangıç sağlık
kontrolü bu yamanın kapsamında değildir. Önceki bundle kurtarma için saklanır.

Windows EXE güncelleme yolu korunmuştur. Native Windows kurulumu ve yayınlanmış
bir macOS release üzerinden gerçek uygulama değişimi henüz uçtan uca denenmedi.

## Diğer 01-01 değişiklikleri

Doğrulama: Java 21 ile launcher `package` başarılı; 18 test, 0 failure,
0 error, 1 platform skip. Beş yeni test bundle konumunu, hatalı hedef reddini,
izole klasörlerde gerçek rename/backup ve yeniden açma hatasında rollback
akışını kapsar. Testler uygulama açma komutunu taklit eder; gerçek uygulama
kurulumunu değiştirmez. Yardımcı shell dosyası sözdizimi kontrolünden geçti.

Çekirdek ve launcher sürümleri 1.0.14'e eşitlendi. Transaction karar logunda
diske zorlama, başlık doğrulama ve boş log onarma eklendi. V1 disk formatları
korundu; fiziksel WAL ve veri redo/undo desteği sonraki çalışma olarak kalıyor.
